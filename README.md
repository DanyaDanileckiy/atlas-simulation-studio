# Atlas Simulation Studio

Профессионально оформленная PWA на основе исходной симуляции гонки населения. В стартовом каталоге 150 стран и 244 города, временная шкала, графики и редактор. Панель «Участники» фильтрует страны и города по стране, континенту, подрегиону, международной организации и населению. Можно включить всех, отключить всех, оставить только совпадения, добавить их или исключить. Списки выбранных участников сохраняются отдельно для стран и городов на устройстве. Измените название проекта, выберите предмет симуляции в верхней панели или настройках, затем настройте метрику гонки.

## Установка на ПК, Android и iPhone/iPad

Для ПК и Android подготовлены отдельные EXE- и APK-установщики; их можно скачать в GitHub Releases. PWA также устанавливается из браузера; для установки сайта с иконкой и автономным запуском он должен быть опубликован на HTTPS-хостинге.

1. Загрузите все файлы папки на HTTPS-хостинг (например, GitHub Pages, Cloudflare Pages, Netlify или собственный сервер).
2. Откройте адрес в Chrome/Edge на ПК или Android и нажмите «Установить приложение» либо выберите установку в меню браузера.
3. На iPhone/iPad откройте сайт в Safari → «Поделиться» → «На экран Домой».

Service worker кэширует оболочку для последующих запусков. Локально сайт удобно открыть через HTTP-сервер, например `python -m http.server 8080`, затем перейти на `http://localhost:8080`. При открытии HTML как `file://` установка недоступна. Исходная ширина визуализации и редактора сохранена; высота окна адаптирована к устройству.

## Языки

Есть выбор из 35 языков: русский, английский, испанский, французский, немецкий, итальянский, португальский, нидерландский, польский, украинский, турецкий, арабский, китайский, японский, корейский, хинди, бенгальский, индонезийский, малайский, вьетнамский, тайский, шведский, норвежский, датский, финский, греческий, иврит, персидский, урду, румынский, венгерский, чешский, словацкий, болгарский и сербский. Названия стран и континентов локализуются для выбранного языка. Интерфейс студийной оболочки полностью переведен на русский, английский, испанский, французский, немецкий, украинский, китайский, японский и арабский; для других языков оболочка переключается на английский. Подписи исходной симуляции и редактора остаются русскими.

## Точность симуляции

Население для новых городов — округленные ориентировочные оценки на 2020 год; границы города и агломерации в исходных наборах могут различаться. Исторические ряды и прогнозы для недавно добавленных городов построены по упрощенной модели для визуализации, а не являются официальным рядом статистики. Режимы ВВП, производства, миграции и преступности позволяют выбрать объект и название проекта, но не подменяют демографические данные статистикой из этих областей: введенные в редакторе исходные ряды все еще являются демографическими. Чтобы режимы давали содержательный результат, редактор нужно доработать для отдельных наборов пользовательских метрик и загрузить для них данные. Поэтому значения конкурирующих метрик с пометкой «демо-индекс» нельзя интерпретировать как реальные показатели.

## Файлы установщиков

Собраны [Windows EXE-установщик](installer-output/AtlasSimulationStudioSetup.exe) и [подписанный Android APK](installer-output/Atlas-Simulation-Studio.apk). Инструкции по установке находятся в `installer-output/README.md`. Ключ подписи APK и пароль хранятся только локально и намеренно не включены в GitHub-репозиторий. EXE устанавливает приложение в профиль Windows и открывает сайт в браузере; SmartScreen может показать предупреждение о неизвестном издателе, так как EXE не подписан сертификатом издателя.

iPhone/iPad: используйте Safari → «Поделиться» → «На экран Домой». Файл iOS IPA не собирался; для его распространения нужны Apple-подпись и iOS build toolchain.
